The console is not running

This page can drive the twin, but only when the twin is serving it. Open a terminal in the folder that holds the extrusion_twin folder and run:

python -m extrusion_twin serve

That starts a small console on your own machine and opens it at http://localhost:8000. Nothing leaves the computer.
